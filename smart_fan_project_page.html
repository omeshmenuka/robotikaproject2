Dual-Mode Smart Fan

A smart fan system with touchless control and automatic temperature control. The fan turns on when a hand comes close to the ultrasonic sensor in manual mode, and it also runs automatically when the room temperature rises above the set threshold in auto mode.

Project Overview

One device, two smart control systems, and a simple simulation-friendly design.

Mode 1

Touchless Manual Mode

The ultrasonic sensor checks the hand distance. When a hand is within about 10 cm, the fan turns on. When the hand moves away, the fan turns off.

Mode 2

Automatic Temperature Mode

The DHT22 reads the room temperature. If the temperature goes above the threshold, the fan turns on automatically. When the temperature drops, the fan turns off.

How It Works

  • Step 1: Arduino reads the DHT22 temperature sensor.
  • Step 2: Arduino reads the HC-SR04 ultrasonic distance sensor.
  • Step 3: The button selects OFF, AUTO, or MANUAL mode.
  • Step 4: In AUTO mode, temperature controls the fan.
  • Step 5: In MANUAL mode, hand distance controls the fan.
  • Step 6: The LED in Wokwi represents the fan state.

Circuit Connections

  • DHT22 VCC → 5V
  • DHT22 SDA/Data → D2
  • DHT22 GND → GND
  • Button → D3 and GND
  • LED Anode (+) → D5 through 220Ω resistor
  • LED Cathode (-) → GND
  • HC-SR04 TRIG → D9
  • HC-SR04 ECHO → D10
  • HC-SR04 VCC → 5V
  • HC-SR04 GND → GND
